## Local installation (recommended)

Install Rust from [rustup.rs](https://rustup.rs) first:

```bash
git clone https://github.com/elithecho/agcu
cd agcu
cargo install --path cli
```

Cargo installs `agcu` to `~/.cargo/bin`; ensure that directory is on `PATH`.
The optional `./scripts/setup.sh` development helper checks Rust/Node, installs JS
dependencies and builds `./cli/target/release/agcu`. It does not install the binary
on `PATH` or grant permissions.

The bundle contains macOS arm64/x64, Linux arm64/x64 and Windows x64 executables.
Linux binaries use GNU libc and dynamically link OpenSSL 3, not Alpine/musl.
Debian 12 container startup checks do not verify desktop accessibility or input
delivery on Linux or Windows.

## Cargo

```bash
cargo install --git https://github.com/elithecho/agcu agcu
```

## From source

```bash
git clone https://github.com/elithecho/agcu
cd agcu/cli
cargo build --release
cargo install --path .
```

## Permissions

agcu needs accessibility access to control apps:

1. Open **System Settings → Privacy & Security → Accessibility**
2. Add your terminal app (Terminal, iTerm2, Warp, Cursor, VS Code)
3. Toggle it on

Verify:

```bash
agcu check-permissions
# → Accessibility permissions: granted
```

## Verify installation

```bash
agcu --version
agcu apps           # should list running applications
```

## Uninstall

If you installed via Cargo (`cargo install`, locally or from Git):

```bash
cargo uninstall agcu
```

If you installed via a Node package manager:
