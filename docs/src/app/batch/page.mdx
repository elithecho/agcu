Pipe a JSON array of commands to `agcu batch` to avoid per-command startup overhead.

## Usage

```bash
echo '[
  ["snapshot", "Calculator", "-i"],
  ["click", "@e5"],
  ["click", "@e8"],
  ["click", "@e11"],
  ["click", "@e20"]
]' | agcu batch
```

## Stop on Error

Use `--bail` to stop at the first failure:

```bash
echo '[["click","@e1"],["click","@e99"]]' | agcu batch --bail
```

## Interactive Explorer

Explore the accessibility tree in a TUI:

```bash
agcu observe -a Calculator        # TUI tree viewer
agcu observe -a Maps -d 5         # Custom depth
agcu observe -a Safari --refresh 1.0
```

**Keys:** `j/k` navigate, `Enter` expand, `/` search, `y` copy selector, `q` quit
