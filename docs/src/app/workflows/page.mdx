<PageHeader title="YAML Workflows" description="Define multi-step automations in YAML files." />

Workflows let you chain multiple agcu commands into a single replayable file.

## Example Workflow

```yaml
app: Maps
timeout: 10
steps:
  - click: 'id="MapsSearchTextField"'
  - type:
      selector: 'id="MapsSearchTextField"'
      text: 'Taj Mahal'
  - key: return
  - wait-for: 'id="ActionRowItemTypeDirections"'
  - click: 'id="ActionRowItemTypeDirections"'
```

## Running Workflows

```bash
agcu run search-maps.yaml                # Execute
agcu run workflow.yaml --app Calculator   # Override default app
agcu run workflow.yaml --dry-run          # Validate without executing
```

## Available Step Types

```yaml
steps:
  - click: '<selector>'
  - type: { selector: '<selector>', text: 'hello' }
  - key: return
  - scroll: { direction: down, amount: 3 }
  - wait-for: '<selector>'
  - open: '<app>'
  - screenshot: { path: 'output.png' }
```
